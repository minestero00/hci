# CRT 판단 지원 연구 실행 계획 · v4

기준: `AI 판단 지원과 독립 수행 자기평가 연구 제안서-redisigned.pdf` (30쪽), 콘텐츠 4.0.0, UI 2026.11.13-crt1. 업무형 v3는 [과거 계획](experiment-plan-v3.md)에 보존한다.

## 질문과 조작

AI가 선택을 도운 직후, 참가자가 AI 없이 바뀐 조건에 원리를 적용하는 자신의 수행을 적절하게 예상하는지 비교한다. 한 참가자가 무지원 또는 정확한 고정 AI 추천·설명 조건으로 세 묶음을 모두 수행한다. 실시간 LLM을 호출하지 않는다. 추천과 설명을 함께 추가한 효과이며 각각의 효과나 장기 능력 감소를 분리해 주장하지 않는다.

## 절차

동의와 외부 도구 미사용 확인 → 성별·전공·AI 이용 빈도·나이·적격성·대면/비대면·기기 → 연습 → 본 과제 3묶음 → 사후 질문.

연습은 왕복 평균 속력이다. 최초 선택 → 확신도(0~100)·적용 예상(0~6) → 적용 3개와 설명 1개 → 제출 후 풀이·채점 예시다. 연습 적용 3개는 블라인드 채점하며 D_기준을 계산한다. 설명 1개는 형식 연습으로 채점하지 않는다.

본 과제는 가격 차이·인쇄 비율·거래 손익이다. 최초 답 선택 → 부담(1~7) → AI 제거 → 확신도·적용 예상·설명 예상 → 적용 3개(무작위 순서) → 설명 2개다. AI는 최초 선택과 부담 단계에만 표시한다. 문제 원문·사칙연산 계산기는 계속 제공하며 질문은 독립적으로 원래 문제에서 출발한다. 정수 예상 세 칸 모두 제출해야 하고 확정 뒤 수정과 AI 재열람을 차단한다.

적용은 숫자 변경(a)·구조 변경(b)·함정 없음(c)을 포함한다. 참가자 화면에는 이 유형 이름을 표시하지 않는다. 4지선다 보기 순서를 참가자별로 섞고 내부 ID와 순서를 따로 보존한다. AI 추천은 값으로 표시해 보기 순서와 어긋나지 않는다. 숫자 답과 풀이를 나눠 입력하며 식 없이 정답만 적으면 1점이다.

사후에는 사용 자료, 예상 근거, 기억한 설명과 원문 활용, 뒤 묶음의 전략 변화, 유사 문제 노출, 외부 도구 사용을 받는다. 비대면은 주의 점검 1개를 추가한다. 인터뷰는 별도 운영한다.

## 배정

순서는 123 / 231 / 312의 라틴 방진이다. 두 집단 × 세 순서 = 6개 조합을 한 블록으로 섞는다. 중앙 배정표는 접속 후 동의한 참가자의 익명 UID별로 하나의 순번을 원자적으로 부여한다. 연결 재시도는 같은 순번을 반환하며 이탈 순번은 재활용하지 않는다. 미래 슬롯 목록 조회는 참가자에게 허용하지 않는다. 현재/이전 익명 슬롯은 동시 트랜잭션 검증을 위해 단건 읽기가 가능하므로 강한 배정 비밀성을 보장하는 서버 함수와는 다르다.

배정표 관리자와 참가자 진행 담당자를 분리하고 진행 담당자에게 중앙 링크만 전달한다. 연구자 권한 계정은 배정표 조회가 가능하므로 이 운영 분리는 필수다. 로컬 초대는 관리자 생성 순번대로 배포하며 중앙 배정과 혼합할 경우 `allocation_source`로 구분한다.

집단 내 대안은 첫 묶음 무지원, 뒤 두 묶음 AI 지원이며 어느 묶음이 처음인지는 세 순서로 돌린다. 첫 참가자 전에만 전환하고 집단 간 자료와 섞지 않는다. 조건은 묶음별 `support` 설정으로 보존한다.

## 점수와 데이터

- 주 지표: D_적용 = 적용 예상(0~6) − 인간 합의 적용 실제(0~6), 세 묶음의 참가자별 평균.
- 필수 보조: D_설명 = 설명 예상(0~4) − 설명 실제(0~4).
- 공변량: D_기준 = 연습 적용 예상 − 연습 적용 실제.
- 자기효능감: 본 묶음 확신도와 연습 SE_기준. 점수와 단위가 다르므로 차이를 계산하지 않는다.
- 적용·설명 실제, 예상, 적용 절대오차, 최초 정답·함정 답, 부담, 유형별 수행, 단계·자료 노출 시간을 따로 보존한다.

미제출·미채점은 결측이다. 모르겠음은 명시적 상태이며 채점 시 0점이다. 두 채점자의 독립 점수와 최종 합의를 모두 보존하고 합의 전 선형 가중 카파를 확인한다. 채점 묶음에는 집단·코드·예상·확신도·부담·시간이 없다. 숫자 확인은 답란에 적힌 명시적 수치·단위만 검사하며 모호한 답이나 자연어는 수동 확인한다. 풀이 유무·단순 계산 실수·관계 이해는 인간이 판단한다. 길이·문체·AI와 표현 일치는 점수 근거가 아니다. 공통 부분점수 규칙은 모든 적용 문항에 적용한다.

30명 × 18개 답변 = 540개, 이중 채점은 1,080건이다. 원문과 [문항표](task-bank-v4.md)를 함께 확인한다.

## 모집과 전환 규칙

대상은 한국어 과제를 이해하는 만 19~29세 대학생이다. 전공·성별 편중을 줄여 모집한다. 제작자·정답 사전 열람자·이전 파일럿 참가자는 제외한다. 완료 목표 30명, 최소선 24명이다. 중간 크기 효과를 확증할 규모로 해석하지 않고 추정치와 신뢰구간을 중심으로 보고한다.

본 실험 전 신청 24명 이상이면 기본 집단 간 설계로 진행한다. 16~23명이면 비대면을 열고 모집 경로를 추가하며 한 번, 최대 1주 연장한다. 16명 미만이면 첫 참가자를 받기 전에 집단 내 대안으로 전환한다.

마감 후 완료 24명 이상이면 사전 고정한 주 분석을 보고한다. 12~23명은 같은 모형의 추정치·95% 신뢰구간만 보고하고 p값은 숨긴다. 12명 미만이면 기술통계·개인별 예상-실제·인터뷰 중심으로 전환한다. 유의성이나 점수를 보고 모집을 늘리거나 끝내지 않는다. 제외 기준과 집단별 제외·중단 수를 별도로 기록한다.

## 사람 파일럿

본 실험과 별도 6~10명, 두 조건을 모두 포함한다. 무지원 3~5명에게만 아래 난이도 기준을 적용한다. AI 집단 차이를 보고 문항을 고르지 않는다.

| 지표 | 기준 |
|---|---|
| 묶음별 적용 평균 | 6점 중 2.5~4.5 |
| 적용 만점 비율 | 절반 이하 |
| 원 문제 정답률 | 20~80% |
| 함정 없는 적용 c 정답률 | 80% 이상 |
| 유사 문제 노출 | 본 적 있음 절반 미만 |

숫자 답만 맞은 유지 문항의 비율과 실제 풀이 전략을 확인한다. 숫자·소재를 조정한 이력과 경계 채점 예시를 남기고 원리는 바꾸지 않는다. 수행·예상·확신도 구분 이해, 기준 D 천장, 문항 힌트, 20~30분 소요, 자동 수신·재개도 확인한다. 난이도 점검 CSV의 수동 확인 답은 직접 판정해야 하며 작은 표본의 통계 검정으로 해석하지 않는다.

## 분석

`analysis/crt-analysis.R`은 참가자 CSV와 묶음 CSV를 입력받는다. 사람 파일럿·팀 체험을 제외하고 `primary_ready`를 통과한 본 실험을 대상으로 한다. 이 표지는 최종 적격 판정이 아니므로 실제 제외 사유와 중단 수는 별도 기록과 함께 보고한다.

주 분석은 참가자 평균 D_적용 ~ 집단 + D_기준의 ANCOVA, HC3 표준오차와 양측 추론이다. 집단별 원평균·SD, 보정 평균, 집단 차이·95% CI, 표준화 차이를 산출한다. 표준화 차이는 보정 집단 차이를 원자료 합동 SD로 나눈 값이며 그 CI는 SD 추정 오차를 포함하지 않는 근사치다.

Welch 비교, 첫 묶음 비교, 순서 보정, 노출자 제외, 비대면 제외를 함께 보고한다. D_설명은 보조 추정과 CI로 해석한다. 확신도는 SE_기준으로 보정하고 실제 적용 점수와의 집단별 상관을 본다. `lme4`가 있으면 D_적용 ~ 집단 × 위치 + 묶음 + D_기준 + (1|참가자)의 탐색 모형을 실행한다. 세 묶음을 독립 참가자로 세지 않는다.

D가 커졌다는 사실만으로 부정확해졌다고 결론 내리지 않는다. 실제·예상·절대오차, 개인별 부호 분포와 a/b/c 유형별 수행을 함께 본다. 비유의가 동등성은 아니다. 모든 결론은 즉시 수행과 이 과제 범위에 한정한다.

## 운영 고정

담당자·연락 방법·보관 종료일·모집 마감·보상·제외 기준·설계 전환은 실제 모집 전에 확정한다. 서버 규칙과 새 Pages 배포 뒤 실제 수신·Google 연구자 로그인과 자료 가져오기 왕복을 확인한다. 자동 시험·에뮬레이터·합성 R 분석은 사람 파일럿과 실제 서버 검증을 대신하지 않는다.
