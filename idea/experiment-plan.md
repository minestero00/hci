# AI 판단 지원 실험 실행 계획

PC 브라우저에서 정확한 고정 AI 지원 유무에 따른 이후 원자료 기반 수행과 자기평가를 비교한다. 현재 구현은 GitHub Pages의 팀 테스트용 정적 파일럿이며 서버 자동 수집은 하지 않는다. 실제 문항·AI 문안·정답·루브릭은 [과제 원문과 채점 기준](task-bank-v3.md), 실행 방법은 [README](../README.md)를 기준으로 한다.

초기 [기획 PDF](<AI 판단 지원이 독립 수행과 자기평가에 미치는 영향.pdf>)와 [HTML 예시](ai_understanding_pilot.html)는 참고 자료다. [이전 파트별 평가](task-review.md)의 수정 방향을 v3 문항에 반영했다. 실제 참가자 난이도·현실감·소요 시간은 사람 파일럿에서 확인해야 한다.

현재 UI 개선, 행동 로그·CSV 명세, 독립 검토와 구현 결론은 [종합 보고서](../docs/final-report.md)에 정리했다. 콘텐츠 3.0.0과 참가자 UI `2026.11.03-ux2`·telemetry 2를 구분하며, 이전 UI 자료를 새 UI의 본 실험에 자동 합치지 않는다.

## 실험 설계

| 항목 | 현재 결정 |
|---|---|
| 조건 | 동일 원자료만 제공 / 동일 원자료에 고정 AI 추천·설명 추가 |
| AI 지원 | 정확성을 검토한 고정 문안. 실시간 대화·의도적 오류 없음 |
| 참여 | PC 브라우저. 대면 필수 아님. 휴대폰은 참여 화면에서 안내 |
| 배정 | 한 참가자는 한 조건. 연구자가 생성한 초대 배치 안에서 균형 배정 |
| 업무 | 행사 예약·공유 권한·제출 계획 세 개 |
| 평가 | 원자료를 유지하고 AI를 제거한 뒤 새 요청 선택형 두 개와 원래 업무 인계 메모 |
| 배점 | 후속 선택형 각 1점 + 설명 0~2점, 사례당 4점 |
| 예상 | 평가 문항 전 0~4점, 0.5점 간격. 확정 후 수정 불가 |
| 주 결과 | 사례별 예상−인간 기준 실제 점수의 참가자별 평균 |
| 채점 | 인간 두 명 독립 채점 후 합의. AI 독립·인간/AI 평균은 보조 |
| 수집 | 현재 기기의 IndexedDB → 참가자가 JSON 전달 → 연구자가 여러 파일 통합 |
| 모집 | 현재 약 20명 예상이며 상한 아님. 실제 마감은 본 실험 착수 전에 기록 |

현재 연구는 추천과 설명 패키지 전체의 효과를 본다. 추천·설명의 개별 효과, AI라는 출처 표시만의 효과, 오류 탐지나 장기 능력 저하를 분리해 주장하지 않는다. 설명 점수는 두 후속 요청 이후의 설명 수행이다. 총점을 순수한 새로운 상황 적용 능력으로 해석하지 않고 적용·설명 점수도 각각 보고한다.

## 참가자 흐름

1. 안내·동의와 익명 코드 확인. 실제 이름·학번·연락처는 받지 않는다.
2. 조작 연습과 4점 척도 안내. 본 업무의 판단 규칙을 가르치지 않는다.
3. 원자료를 확인하고 실행안 선택. AI 지원은 배정된 조건에만 제공한다.
4. 정신적 부담 1~7점과 다음 평가의 예상 점수 확정.
5. AI 제거 후 첫 후속 요청에 응답·확정.
6. 두 번째 후속 요청에 응답·확정. 두 변경은 각각 원래 상황에서 출발한다.
7. 원래 업무에 대한 짧은 인계 메모 작성. 항목식 설명과 모르겠음 허용.
8. 세 업무 완료 후 전체 응답·로그 JSON을 다운로드해 연구 담당자에게 전달.

조작 연습 한 단계와 업무당 다섯 단계로 총 16개 제출 단계다. 정답·점수는 참가자 화면에 표시하지 않는다. 제출한 단계는 수정하지 못하고 새로고침·재접속은 저장된 단계와 초안을 복구한다. 저장에 실패하면 상태를 알리고 현재 기록을 파일로 보관할 수 있게 한다.

두 조건의 원자료·기본 배치·폭은 동일하다. AI가 제거된 뒤에도 원자료를 계속 참고할 수 있다. 평가 중에는 원래 후보 절차도 원자료에 남긴다. 첫 추천 이름을 반복하는 대신 변경된 적격성·권한·제출 결과를 응답에서 판별하게 한다. 제출 계획의 합리적인 순서 조정은 정답으로 인정한다.

본 실험에서는 풀이를 도와주거나 생각을 소리 내게 하지 않는다. 대면·원격 여부, 화면 크기와 연구자 개입은 운영 기록으로 남긴다. 원격 참여 안내와 재접속도 파일럿에서 확인한다.

## 정적 초대와 데이터 전달

기본 주소에서 시작하는 실행은 ‘팀 체험’으로 표시하고 주 분석에서 기본 제외한다. 연구자 작업실에서 초대 배치를 생성하면 초대 참여로 기록한다. 배치별 익명 코드와 고유 초대 ID를 사용하며 조건은 4명 블록에서 2명씩 나누고 조건별 사례 순서 6가지를 섞어 사용한다. 후속 요청 순서도 배정 후 고정한다.

정적 페이지는 전 기기의 배정 상태를 공유하지 않는다. 배치 간 균형이나 링크 재사용을 서버가 보장하지 않으므로 담당자가 초대 목록을 관리한다. 같은 초대 ID의 여러 실행은 CSV에 표시하고 주 분석 가능 표지에서 제외해 담당자가 중복 여부를 검토하게 한다.

참가자와 연구자 자료는 각자의 브라우저에만 저장된다. 참가자는 최종 다운로드 파일을 담당자에게 전달하고, 담당자는 전체 보관 JSON을 별도로 보관한다. 동일 실행의 동일 파일은 중복 제거하며 다른 응답·로그가 있는 파일은 기존 자료를 보존하고 충돌로 알린다. 중단·미채점·저장 실패는 0점과 구분한다.

정적 자산과 연구자 도구는 공개되어 있다. 참가자 앱은 연구자 정답 모듈을 불러오지 않지만 기술적인 비밀성·인증·변조 방지를 보장하지 않는다. 본 버전은 안내된 팀 테스트와 파일럿을 위한 것이며, 중앙 자동 수집이 필요한 본 실험에서는 별도 서버 연결을 검토한다.

## 채점과 분석

선택형은 고정 정답으로 계산하고 최초 실행안 선택은 보조 결과로만 기록한다. 서술형은 두 관계 기준을 모두 정확히 연결하면 2점, 유효한 부분근거는 있지만 불완전하거나 결론 오류가 있으면 1점, 유효한 근거가 없거나 모르겠음이면 0점이다. 길이·문체·AI 표현 일치는 가점하지 않는다. 세부 기준·동등 표현·혼합 답안은 실제 문항 문서를 따른다.

인간 채점자는 조건·예상 점수·최초 선택·행동 로그·다른 사람과 AI의 점수를 숨긴 채점 묶음으로 독립 채점한다. 각자 별도 브라우저에서 수행한 결과를 전달한다. 두 점수가 있어야 합의 점수를 입력·가져올 수 있다. 개별 점수·근거와 합의 사유는 보존한다. 연구자 도구의 역할 선택은 기술적 인증이 아니므로 독립 운영 절차를 지킨다.

AI는 같은 익명 답안·원자료·루브릭·검토된 예시로 별도 채점한다. 현재 웹은 입력 묶음을 내보내고 결과 JSON을 연결하는 기능만 제공하며 외부 모델을 자동 호출하지 않는다. 실제 실행의 모델·프롬프트 버전, 점수·근거를 함께 저장한다. 실패는 미채점이며 재시도를 0점으로 대체하지 않는다.

선택형 합계를 M, 인간 합의 설명 점수를 H, AI 설명 점수를 L이라 하면 주 분석의 실제 점수는 M+H, AI 보조는 M+L, 평균 보조는 M+(H+L)/2다. 미채점은 빈칸이다. 세 사례의 응답과 인간 합의 점수가 모두 있어야 참가자 평균 실제 점수와 평균 차이를 계산한다.

사례별 E−S의 참가자 평균을 주 분석 단위로 한다. 평균 절대오차는 mean(|E−S|)로 구하고 abs(mean(E−S))로 대신하지 않는다. 집단 평균·SD, AI−무지원 평균차·95% 신뢰구간, Welch 양측 검정, 개인별 분포를 보고한다. 표본이 작으면 근사 추론의 불확실성을 밝힌다. 실제 점수·예상 점수·적용·설명·0점/4점 빈도도 함께 본다.

차이값 증가 자체를 자기평가 악화로 해석하지 않는다. −1에서 0으로 바뀌면 차이는 커져도 더 정확해진다. 실제 4점이면 예상 척도 상한 때문에 과대평가를 관찰할 수 없다. 비유의 결과도 동등성이나 효과 없음을 입증하지 않는다.

참가자별 CSV의 primary_eligible은 초대 참여·완료·세 사례 인간 채점·중복 초대 미발견을 확인하는 자료 준비 표지다. 실제 적격·제외 판단까지 자동 확정하는 값은 아니다. 낮은 점수·빠른 응답·탭 이탈만으로 제외하지 않는다. 미동의·사전 부적격·제작자·파일럿·확인된 중복은 사유를 남겨 제외한다. 집단별 중단·제외를 보고하고 부분 완료자는 보조 자료로 확인한다.

본 실험 첫 참여 전에 모집 경로·적격 기준·마감 시각·담당자·보관 종료일을 기록한다. 집단 차이나 p값을 보고 모집을 종료·연장하지 않는다. 20명은 자원에 따른 예상치이며 검정력을 보장하지 않는다. 웹의 CSV는 후속 통계 분석용 자료이며 브라우저가 p값을 자동 산출하지는 않는다.

## 행동 로그

웹 안에서 진행·클릭·선택 변경·키보드 탐색·입력 유형·붙여넣기 발생·화면 노출·탭/창 상태·저장 상태를 기록한다. 포인터는 움직일 때 200ms, 스크롤은 250ms 간격 표본과 종료 위치를 기록한다. 답안 수정본은 500ms 유휴·연속 입력 중 2초·조합 완료·포커스 이탈에 보존한다. 원문 키 입력이나 클립보드 전체를 별도로 저장하지 않는다.

이벤트 ID, 실행/페이지 ID, 순번, 단계·업무·요청 ID, UTC 시각과 단조 증가 시간을 연결한다. IndexedDB에 배치 저장하며 실패한 대기 기록은 유지한다. 정상 저장이 어려우면 파일에 대기 로그와 복구 경고를 포함한다. 연구자 탭은 저장 revision 충돌을 검사해 오래된 화면이 최신 채점을 덮지 못하게 한다.

기하학적 화면 노출은 읽기·이해의 증거가 아니다. 탭 이탈도 외부 AI 사용의 증거가 아니다. 행동 로그는 사전 정의한 단계 시간·선택 변경·원자료/AI 노출 요약과 탐색 자료로 구분한다. 로그·사례 수를 독립 참가자 수로 세지 않는다.

전경·숨김·창 비활성 시간을 분리하고, 전경에서 최근 30초 조작이 없는 구간도 별도로 보존한다. 무입력이 곧 비참여라는 뜻은 아니다. 도움·중단 대화상자가 가린 자료의 노출은 중단하며 중간 다운로드에는 진행 중인 집계를 포함한다. 실행·단계·자료별 행동 CSV를 제공하고 이전 형식에 없는 시간은 결측으로 둔다. 세부 정의·이벤트와 보관 한계는 [행동 로그 명세](../docs/final-report.md#6-행동-로그-명세)를 따른다.

## 사람 파일럿과 본 실험 진입

우선 4명으로 시작한다. 각 조건 1명씩은 생각을 소리 내며 이해·조작을 확인하고, 다음 각 조건 1명씩은 말없이 전체 절차를 따른다. 문제가 남으면 2명 이상 추가해 수정된 흐름을 확인한다. 파일럿은 본 분석에서 제외한다. 목표 20~25분은 아직 실측값이 아니다.

다음이 확인된 뒤 본 실험 문항·AI 실행·절차 버전을 고정한다.

- 원자료와 새 요청의 단일 정답, 두 인간의 독립 검산과 서술형 경계 채점.
- 추천 이름만 기억했을 때와 새 관계를 적용했을 때의 응답 구별.
- 예상 점수와 독립 변경의 이해, 문구·산술·탐색 부담의 적정성.
- 두 조건의 배치, AI 제거, 원자료 유지, 재접속과 초안 복구.
- 완료·중단 파일 내보내기, 연구자 병합, 독립 채점·합의, CSV 재계산.
- 실제 지원 PC 브라우저의 화면·키보드·한글 입력·다운로드 확인.

현재 자동 시험과 AI 독립 검토는 사람 파일럿을 대신하지 않는다. 만점·영점 몰림이나 부수적인 읽기 부담은 수정 경보로 사용하고 원하는 집단 효과가 나온 문항만 골라 채택하지 않는다.
