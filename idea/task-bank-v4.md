# CRT 문항과 채점 기준 · 4.0.0

기준: redisigned.pdf 7~10장. 실행 원문은 web/crt/content.mjs, 정답은 key.mjs와 feedback.mjs다. 보기 순서와 적용 a/b/c 순서는 배정 시 무작위로 고정한다. 아래 유형 이름과 정답은 연구자용이며 참가자 평가 화면에는 표시하지 않는다.

## 공통 연습

같은 길로 도서관까지 갈 때는 시속 6km, 돌아올 때는 시속 3km로 걸었습니다. 왕복 전체의 평균 속력은 시속 몇 km입니까?

- 3km
- 4km (정답)
- 4.5km
- 6km

### p1 · 적용

갈 때는 시속 12km, 돌아올 때는 시속 4km라면 왕복 평균 속력은? 답과 풀이를 쓰세요.

변경: 갈 때 12km/h, 돌아올 때 4km/h

정답·근거: 편도 12km면 갈 때 1시간, 올 때 3시간. 24km ÷ 4시간 = 6km/h

### p2 · 적용

갈 때와 돌아올 때 모두 시속 5km로 걸었다면 왕복 평균 속력은? 답과 풀이를 쓰세요.

변경: 양쪽 모두 5km/h

정답·근거: 양쪽 속력이 같아 전체 속력도 5km/h

### p3 · 적용

처음 1시간은 시속 6km, 다음 1시간은 시속 3km로 걸었다면 2시간 전체의 평균 속력은? 답과 풀이를 쓰세요.

변경: 같은 거리 왕복 대신 각 속력으로 1시간씩 이동

정답·근거: 같은 시간씩 이동하므로 (6 + 3) ÷ 2 = 4.5km/h

### p4 · 설명

원래 문제에서 답이 4.5km가 아닌 이유를 설명하세요.

변경: 원래 문제

정답·근거: 느린 속력으로 걷는 시간이 더 길다. 편도 6km면 12km ÷ 3시간 = 4km/h

## difference

사과 한 상자와 배 한 상자를 합쳐 33,000원입니다. 사과 상자는 배 상자보다 30,000원 비쌉니다. 배 한 상자는 얼마입니까?

- 1,500원 (정답)
- 3,000원
- 16,500원
- 30,000원

AI 지원: 1,500원 추천. 배 상자를 x원이라 하면 사과 상자는 x + 30,000원입니다. 두 상자의 합은 2x + 30,000 = 33,000이므로 x = 1,500원입니다. 3,000원으로 생각하기 쉽지만, 그러면 사과 상자가 33,000원이 되어 두 상자의 합이 36,000원이 됩니다.

### a · 적용

두 상자를 합쳐 34,000원이고, 사과 상자가 배 상자보다 31,000원 비쌉니다. 배 상자는 얼마입니까? 답과 풀이를 쓰세요.

변경: 합 34,000원 / 가격 차이 31,000원

정답·근거: 2x + 31,000 = 34,000 또는 사과 32,500원과 배 1,500원의 합 검산

### b · 적용

두 상자를 합쳐 33,000원이고, 사과 상자 가격은 배 상자 가격의 2배보다 3,000원 비쌉니다. 배 상자는 얼마입니까? 답과 풀이를 쓰세요.

변경: 사과 가격 = 배 가격의 2배 + 3,000원

정답·근거: 3x + 3,000 = 33,000

### c · 적용

사과 상자는 30,000원이고, 두 상자를 합친 가격은 33,000원입니다. 배 상자는 얼마입니까? 답과 풀이를 쓰세요.

변경: 사과 가격 자체가 30,000원 / 합 33,000원

정답·근거: 33,000 − 30,000

### d · 설명

원래 문제에서 배 상자가 3,000원이 아닌 이유를 수치로 설명하세요.

변경: 원래 문제

정답·근거: 배가 3,000원이면 사과 33,000원, 합 36,000원으로 조건 불일치

### e · 설명

두 상자의 합은 33,000원 그대로이고, 가격 차이만 31,000원으로 커지면 배 상자 가격은 어떻게 바뀝니까? 이유와 함께 쓰세요.

변경: 가격 차이만 31,000원

정답·근거: 줄어든다. (33,000 − 31,000) ÷ 2 = 1,000

## rate

프린터 3대가 3분 동안 전단지 3묶음을 인쇄합니다. 같은 프린터 30대가 전단지 30묶음을 인쇄하려면 몇 분이 걸립니까? 모든 프린터는 동시에 같은 속도로 인쇄합니다.

- 1분
- 3분 (정답)
- 10분
- 30분

AI 지원: 3분 추천. 프린터 3대가 3분에 3묶음을 인쇄하므로, 프린터 1대는 3분에 1묶음을 인쇄합니다. 프린터 30대가 동시에 인쇄하면 3분 동안 30묶음을 인쇄합니다. 30분으로 생각하기 쉽지만, 프린터 수와 묶음 수가 같은 비율로 늘면 걸리는 시간은 변하지 않습니다.

### a · 적용

같은 프린터 12대가 전단지 12묶음을 인쇄하려면 몇 분이 걸립니까? 답과 풀이를 쓰세요.

변경: 프린터 12대 / 전단지 12묶음

정답·근거: 한 대가 3분에 1묶음. 12대가 3분에 12묶음

### b · 적용

더 빠른 기종은 3대가 3분 동안 6묶음을 인쇄합니다. 이 기종 6대가 36묶음을 인쇄하려면 몇 분이 걸립니까? 답과 풀이를 쓰세요.

변경: 새 기종: 3대·3분·6묶음 / 이 기종 6대·36묶음

정답·근거: 새 기종 한 대가 3분에 2묶음. 6대가 3분에 12묶음, 36묶음은 9분

### c · 적용

원래 프린터 3대로 전단지 6묶음을 인쇄하려면 몇 분이 걸립니까? 답과 풀이를 쓰세요.

변경: 원래 프린터 3대 / 전단지 6묶음

정답·근거: 대수는 같고 작업량이 2배여서 시간도 2배

### d · 설명

원래 문제에서 답이 30분이 아닌 이유를 설명하세요.

변경: 원래 문제

정답·근거: 한 대가 3분에 1묶음, 30대가 동시에 일해 3분에 30묶음

### e · 설명

인쇄할 양은 3묶음 그대로이고 프린터만 6대로 늘리면 걸리는 시간은 어떻게 바뀝니까? 이유와 함께 쓰세요.

변경: 기준 3대·3묶음에서 프린터만 6대로 변경

정답·근거: 줄어든다. 같은 작업을 2배의 프린터가 나눠 맡아 절반인 1분 30초

## trade

중고 카메라를 60만 원에 사서 70만 원에 팔았습니다. 그 카메라를 다시 80만 원에 사서 90만 원에 팔았습니다. 전체 이익은 얼마입니까? 다른 비용은 없습니다.

- 0원 (손익 없음)
- 10만 원
- 20만 원 (정답)
- 30만 원

AI 지원: 20만 원 추천. 두 번의 거래를 각각 계산합니다. 첫 거래는 60만 원에 사서 70만 원에 팔아 10만 원 이익, 두 번째 거래는 80만 원에 사서 90만 원에 팔아 10만 원 이익입니다. 10만 원으로 생각하기 쉽지만, 다시 80만 원에 산 것은 손해가 아니라 두 번째 거래의 구입 비용입니다. 들어온 돈과 나간 돈으로 보아도 −60 + 70 − 80 + 90 = 20만 원입니다.

### a · 적용

70만 원에 사서 80만 원에 팔고, 다시 90만 원에 사서 100만 원에 팔았습니다. 전체 이익은? 답과 풀이를 쓰세요.

변경: 구입·판매 금액 70 → 80 → 90 → 100만 원

정답·근거: −70 + 80 − 90 + 100 = 20만 원 또는 각 거래 +10만 원

### b · 적용

60만 원에 사서 70만 원에 팔고, 다시 80만 원에 사서 75만 원에 팔았습니다. 전체 이익은? 답과 풀이를 쓰세요.

변경: 마지막 판매 가격만 75만 원

정답·근거: 첫 거래 +10만 원, 두 번째 −5만 원, 합 +5만 원

### c · 적용

60만 원에 사서 70만 원에 팔고, 다시 70만 원에 사서 80만 원에 팔았습니다. 전체 이익은? 답과 풀이를 쓰세요.

변경: 구입·판매 금액 60 → 70 → 70 → 80만 원

정답·근거: 각 거래 +10만 원, 합 20만 원

### d · 설명

원래 문제에서 이익이 10만 원이 아닌 이유를 설명하세요.

변경: 원래 문제

정답·근거: 두 거래 각각 +10만 원. 재구입 80만 원은 두 번째 거래 비용이며 별도 손해가 아님

### e · 설명

원래 거래에서 두 번째로 살 때 가격만 85만 원으로 오르면 전체 이익은 어떻게 바뀝니까? 이유와 함께 쓰세요.

변경: 두 번째 구입 가격만 85만 원

정답·근거: 줄어든다. 두 번째 이익이 5만 원으로 줄어 전체 15만 원

## 공통 루브릭

### 적용

- 0점: 오답·함정 답·모르겠음. 관계를 잘못 적용한 것은 단순 계산 실수가 아니다.
- 1점: 정답만 있고 풀이가 없거나, 올바른 풀이에 단순 계산 실수 하나가 있다.
- 2점: 정답과 올바른 식·계산·핵심 관계가 함께 있다.

### 설명

- 0점: 결론이 틀렸거나 모르겠음.
- 1점: 방향·결론만 맞거나 근거가 불완전하다.
- 2점: 올바른 결론과 수치·관계에 근거한 설명이 있다.

결측은 0점과 구분한다. 연습 설명 p4는 형식 연습용으로 채점하지 않는다. 숫자·단위 확인은 보조이며 2점 확정은 인간 풀이 검토 후 가능하다.

### 문항별 경계 우선 적용

위 공통 기준보다 `web/crt/key.mjs`의 `ITEM_RUBRICS`에 고정한 문항별 0·1·2점 기준과 예시를 우선 적용한다. c 문항의 1점은 정답만 있는 경우이며 계산 실수 부분점수를 일반화하지 않는다. 거래 b 문항은 올바른 단계별 풀이에서 명확한 부호 실수 하나를 1점으로 인정한다. 채점자는 블라인드 묶음의 문항별 기준을 사용하고, 새 경계 사례는 독립 채점을 마친 뒤 합의 기록으로 남긴다.
