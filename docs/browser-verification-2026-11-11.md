## 경미한 발견

- 로컬 브라우저 콘솔의 오류 1건은 `/favicon.ico` 404였다. 참가자 앱 모듈·CSS는 200으로 로드됐다.
- 실제 Pages 초기 화면에서도 favicon 404가 발생했다.
- 연구자 참여 링크 화면의 Lighthouse snapshot은 meta description 누락을 보고했다. 연구자 도구이므로 기능상 우선순위는 낮다.
- 로컬 연구자 화면과 원자료 참가자 실행에서 애플리케이션 console error/warn은 관찰하지 못했다.

성능 측정은 수행하지 않았다.

## 남은 검증

- Firebase 실제 응답 업로드·최종 수신 확인·전송 실패 재시도는 이번 브라우저 시험에서 실행하지 않았다. 로컬 `cloud=1`은 사용하지 않았다.
- 연구자 Google 팝업 로그인과 권한 있는 서버 자료 가져오기는 실행하지 않았다.
- 한글 문자열 입력·보관은 확인했지만 실제 한글 입력기의 조합 중 키 입력은 검증하지 않았다.
- 다운로드 버튼과 생성 JSON 내용은 확인했지만 OS 다운로드 폴더의 파일 저장 완료는 확인하지 않았다.
- 두 채점자의 독립 채점·합의·분석 CSV 전체 왕복, 다중 탭 충돌, 다른 브라우저와 스크린리더는 이번 범위에 포함하지 않았다.
- 합성 응답을 자동 입력했으므로 실제 참가자의 이해·읽기 부담·소요 시간·문항 난이도의 증거로 사용하지 않는다.

합성 응답 원문과 행동 로그는 저장소에 추가하지 않았다. 실제 수집 서버에 합성 실행을 제출하지 않았다.
