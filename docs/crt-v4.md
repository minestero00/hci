### 실제 서버·Chrome에서 확인한 범위

2026-11-13 crt1의 실제 Pages에서 팀 체험 1회와 중앙 배정 두 조건 각 1회를 33단계 완료하고 최종 수신을 확인했습니다. 중앙 순번 1(control) 뒤 ‘새 참여 준비’로 UID가 교체되고 순번 2(assisted)를 받았습니다. 두 조건 각각 계산기 31개 화면의 초기화, AI 패널 무지원 0개/지원 6개 화면(본 선택·부담) 표시를 확인했습니다.

실제 CRT 라이브 시험은 6명 동시 배정·6조합 균형·동일 UID 재시도·순번 소진·타인 claim/목록/run 읽기 거부와 두 조건의 33단계 수신·미완료/완료 가져오기를 확인했습니다. 배정표 게시와 제한된 합성 run 가져오기는 **관리자 CLI의 IAM 전송**입니다. Google 브라우저 사용자에게 Rules가 허용되는지의 증거가 아닙니다.

마지막 전체 라이브 시험의 정리 기록은 정확한 문서 경로 22개 정리 요청, 익명 계정 8개 삭제, 클라이언트 7개 종료입니다. 22개에는 생성되지 않은 claim 경로도 포함됩니다. 별도 브라우저 run 3개·배정표 1개와 임시 계정 3개도 정리하고 해당 루트 부재를 확인했습니다. 정리 범위는 자신이 만든 합성 자료이며 실제 연구 자료 삭제가 아닙니다.

### crt2 UI 확인

현재 화면은 절차·사용 자료·기록/보관 안내, 큰 단계/현재 할 일, 확신·적용·설명 카드, 좁은 화면의 원문/응답 이동을 제공합니다. 오류 요약은 입력으로 이동하고 보조 설명을 유지합니다. 연구자 화면은 준비 상태·목적별 내보내기·빈 자료 처리·채점 포커스 복원을 지원하며 블라인드 화면에는 관리 현황을 표시하지 않습니다.

2026-11-13 로컬 Chrome에서 1440×900, 375×812, 812×375, 축소 모션·어두운 OS 선호 아래 고정 밝은 화면·CSS 200% 확대를 확인했습니다. 관찰한 예상/빈 분석 화면에 가로 넘침이 없었고, 데스크톱 본 과제 예상의 세 입력과 제출 버튼이 첫 화면에 들어왔습니다. 실제 스크린리더·OS 최대 글자 크기·모든 문항/기기 조합을 검증한 것은 아닙니다. [UI PR](https://github.com/minestero00/hci/pull/3)
